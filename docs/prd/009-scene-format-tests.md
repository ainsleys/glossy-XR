# 009 · Every scene format the viewer accepts is loaded by a test

## Problem

`client/src/loaders.js` loads glTF/GLB (with Draco, KTX2 and meshopt), PLY (mesh, point cloud, or Gaussian splat by header), PCD, OBJ with MTL, `.splat`/`.ksplat`/`.spz`/`.sog` through Spark, flat images, 360 panoramas and video. The suite exercises only the default room and, when a 60 MB interior is present outside the repo, one OBJ (`test/scene.spec.js`). The README records a manual check of each format on 12 Oct. A regression in any loader, in the Gaussian-PLY sniff, in the splat anchor cone test, or in auto-fit for a given format would pass the suite.

## Goal

Each format has an automated load test that runs on every machine, from small fixtures the test writes itself, plus an optional pass over real files when `../test-assets` is present.

## Requirements

R1. **Synthetic fixtures, generated by the test** (no large binaries in the repo): a unit cube as ASCII PLY with faces (mesh); the same vertices as PLY without faces (point cloud); a PLY with the 3DGS header properties (`f_dc_0`, `scale_0`, `rot_0`…) and ~200 Gaussians placed on a sphere (splat via the PLY sniff); a `.splat` file of the same 200 Gaussians in the 32-byte binary layout Spark reads; an ASCII PCD of ~500 coloured points; a minimal glTF (`.gltf` JSON with an embedded base64 buffer, one triangle-list cube); an OBJ cube with a sidecar MTL; a 2:1 PNG panorama and a non-2:1 PNG photo (drawn with a canvas in the test or written as raw PNG bytes); a short silent WebM video if one can be produced without ffmpeg at test time (otherwise skip video with a reason). Fixture writers live in `test/fixtures/scenes.mjs`.

R2. **Per-format load test**, `test/formats.spec.js` under the `chromium` project: for each fixture, upload it as an asset (`uploadAsset` helper), and assert through `window.__glossy.loaded`: the asset's `type` as the server classified it, the model's `kind` (`mesh`, `points` or `splat`), `count > 0` (vertices, points or Gaussians), a bounding box with positive extent, the default room hidden, the asset auto-fitted (saved transform non-empty) and resting on the floor (box min y ≈ 0 within tolerance), and for meshes and point clouds that an annotation can be anchored on it (aim at the object, record a short clip, `anchor.objectId` set for meshes). For splats assert the cone-test anchor lands within the sphere's radius of a Gaussian. For images assert the plane or sphere mode as the README describes; for the panorama, that the camera is inside the sphere.

R3. **Optional real-asset pass**: when `../test-assets` exists, the same assertions over `SheenChair.glb`, `cosmic-buddha-100k-2048_std_draco.glb` (Draco), `stanford_bunny_bun_zipper_mesh.ply`, `colored_cloud.pcd`, `hornedlizard.spz`, and a panorama from `panorama/`; each skipped individually with a reason if its file is missing. Frame time logged, not asserted (software GL).

R4. **Error path**: an upload with an unsupported extension is refused (400) and a corrupt PLY produces a loader error surfaced in `loaded.get(id).error` without taking the page down.

R5. **README**: the test-coverage paragraph names the formats covered and the optional real-asset pass.

## Non-goals

- No change to `client/` or `server/` beyond what a bug found by a new test would need, and then only after reporting it; a loader bug is its own change.
- No performance assertions.
- No headset run (WebXR with splats on hardware is a separate session).

## Design

Fixture writers are pure Node functions returning Buffers; the spec writes them to a temp dir per test. Use `uploadAsset` from `test/helpers.js`. Keep per-format tests separate so a failure names the format. Total added fixture bytes written at runtime, not committed.

## Tests

T1. `npx playwright test test/formats.spec.js`: all formats pass on this machine (real-asset pass included, since `../test-assets` exists here). Mutations, one per family: (a) in `loaders.js` make `isGaussianPly` return false → the 3DGS-PLY test fails (loaded as points, kind mismatch); (b) break the `.splat` case in `loadModel` → the splat test fails; (c) make `autoFit` skip → the "resting on the floor" assertions fail. Restore each.

T2. Stability: `--repeat-each=3` on the spec.

T3. Full `npm test` at the final commit: all passed (the interior scene test runs here since the asset exists).

## Definition of done

- R1–R5; T1 with mutations, T2, T3 in the pull request.
- Commit messages and the pull request describe the change only.
